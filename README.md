# RIVL

Basketball, one screen. NBA, WNBA and college with your teams first: live scores, standings, players, injuries and news.

Static app on GitHub Pages: https://raylikeray.github.io/rivl/

Scores, stats, injuries and news come from ESPN's public feeds. Win chances are RIVL's own estimate, tuned nightly in the `tipoff` repo, whose `data/` this app reads.
